# Bingshen (Benjamin) Lau

Personal website: https://himecorleone.github.io/

The repository root contains the static website served by GitHub Pages.
`website-source.zip` contains the editable React source, original assets and retained Chinese translations.

To rebuild: extract the source archive into an empty directory, run `npm ci`, then `npm run build` and `node scripts/export-github.mjs`. The GitHub Pages files are written to `outputs/github-pages/`.

The public website currently displays English only. Chinese translations and the Chinese CV are retained in the source archive for later use.
